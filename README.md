# news_explorer

The News Explorer project is a simple web application that displays news articles in a dynamic, user-friendly way. It allows users to search and sort news articles. The application is built using HTML, CSS, and JavaScript.

Overview
This project consolidates news articles into a single page, where users can:
* Sort news articles by date with the latest appearing first.
* Filter articles based on categories.
* Search news articles by title.
* Expand the list of articles with a "Show More" button.

Features
* Dynamic News Display
* Debounced Search
* Category Filtering

Technologies Used
* HTML.
* JavaScript: Handles the core logic, including displaying articles, sorting, filtering, and managing user input.
* CSS
